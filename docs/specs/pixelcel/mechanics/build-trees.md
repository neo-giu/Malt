# build-trees (T05) — Malt node API facts, status: done

Probe output (`_probe_tree_api`, build/pixelart/P/t05/stdout.txt of launch 1):
- A new `MaltTree` with `graph_type = 'Mesh'` has ONE node: `MaltIONode` named `MAIN PASS PIXEL SHADER Output`
  (`io_type` `MAIN_PASS_PIXEL_SHADER`, `is_output` True). There is no pre pass node.
- Its inputs: `Color`, `Line Color`, `Line Width`, `Custom Output 1`. No outputs. (`Opacity Mask` does not exist.)
- Pre pass output node: not in the base tree. The plan adds it with `nodes.new('MaltIONode')`, then sets `name`,
  `is_output = True`, `io_type = 'PRE_PASS_PIXEL_SHADER'` (`_pre_pass_node`). Its socket names: not confirmed
  (the struct `PrePassOutput` has normal, id, opacity, transparent_shadowmap_color); the code picks the input whose
  name ends with `opacity`.
- Library keys: `NPR_Pipeline - PixelCel - pixel_cel`, `NPR_Pipeline - PixelCel - pixel_cel_opacity`.
  `find_function(tree, 'pixel_cel')` works (function `name` field). Output sockets of pixel_cel: `color`, `line_color`.
- Custom outputs: `MaltIONode.custom_parameters` (collection of MaltIOParameter, empty on `suz`),
  `allow_custom_parameters` True, `custom_pass` 'Default'. Item fields were not printed (collection empty).

Differences from the plan code:
- Added `_pre_pass_node` (above).
- Added `tree.update_ext(force_track_shader_changes=False, force_update=True)` at the end of `build_tree` and
  `MaltMaterial.track_shader_changes(force_update=True)` at the end of `convert_objects`. Malt calls `update_ext`
  only for the tree shown in an editor (`MaltTree.update`, `is_active()`), so a script-built tree kept the 136 byte
  empty shader in `.malt-autogenerated/testmalt-<tree>.mesh.glsl`.

Causes of the failed renders (fixed by the orchestrator):
- Empty frames: the Malt server restarts after the conversion, so the materials were not compiled when the render
  started. `tools/pixelart/render_gui.py` now waits (max 60 s) until every visible material is in
  `MaltMaterial._MATERIALS` before it renders ("ready waited Xs" in log.txt).
- Defaults only (white base, default tint): `params[key] = True` does not set a Malt bool. Bools live in
  `tree.malt_parameters.bools[key].boolean` (`_set` handles them now). Textures: `textures[key].texture`.
